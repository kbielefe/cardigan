# Pattern import

Operate. The knitter, at the LK150 or the TH-160 with the browser beside the machine, brings a pattern in as paste, a URL, or a PDF or TXT file.

Job: hold that pattern's own words as a reading the knitter can check. Count confirms them. Machine choice, passes, a library, and a second source stay out.

Constraints: words only. No OCR. A scan with no text layer fails and offers paste. Charts and photos stay out. DOMAIN.md is not used. Do not invent pattern text. The product stack stays undecided.

Direction: the pattern leaflet. Memorable moment: the abbreviations box, apart from the instructions, holding a list only when the pattern already headed one.

## Direction contract

THESIS: This surface holds the pattern's own words until the knitter counts them. It refuses a library, a machine picker, and a pass list.

OWN-WORLD: Madder bar #8C2F2F, paper #F7F4EE, ink #1C1C1C, system type. The abbreviations box is a madder-ruled inset (#F3E6E4 ground, 2px madder edge), apart from the reading. Tabs and buttons are plain rectangles in that same madder. The signature is that box: the pattern's list, or the sentence that Cardigan does not add one.

STORY: The knitter brings a pattern in, reads the words and any glossary the pattern already headed, fixes a bad extraction, then counts that reading or discards it.

FIRST VIEWPORT: A full-height column. Madder header with the word Cardigan. Under it, tabs Paste / URL / PDF or TXT and the control for the selected tab. A source line. A scrolling sheet: the abbreviations box, then the reading, both capped near 740px. Footer pinned, with Count this as the pattern as the primary action and Discard beside it. Header, intake, and footer stay put. The box and the reading scroll.
